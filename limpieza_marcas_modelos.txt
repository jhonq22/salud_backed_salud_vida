1. DESCRIPCIÓN Y OBJETIVO
--------------------------------------------------------------------------------
En el módulo de Protocolo de Implantación (/atencion-medica/solicitudes/:id), los 
selectores desplegables de GENERADOR, ELECTRODO VENTRICULAR y ELECTRODO AURICULAR 
consumen los siguientes endpoints:
  - Generadores:             GET /api/listas/marcapasos-marcas/1  (tipo_marca_id = 1)
  - Electrodos Ventriculares: GET /api/listas/marcapasos-marcas/2  (tipo_marca_id = 2)
  - Electrodos Auriculares:   GET /api/listas/marcapasos-marcas/3  (tipo_marca_id = 3)
  - Modelos asociados:       GET /api/listas/marcapasos-modelos/:marca_id

Dichos endpoints filtran únicamente registros con "estatus = 1".
Para limpiar los listados y permitir la inserción de nuevos registros sin perder
la integridad referencial del historial de operaciones de los pacientes, se 
verificaron todas las operaciones guardadas en las tablas:
  - `generador_implantado`
  - `electrodo_verticular_implantado`
  - `electrodo_auricular_implantado`

Aquellos elementos (marcas y modelos) que NO poseen operaciones guardadas se 
desactivan estableciendo su columna `estatus = 0` (false).

6. QUERY SQL DINÁMICO (VERIFICACIÓN AUTOMÁTICA DIRECTA EN BASE DE DATOS)
================================================================================

-- Si se desea ejecutar un script dinámico que determine automáticamente cuáles 
-- marcas y modelos no tienen registros y los desactive:

-- A) Desactivar marcas que no existan en ninguna de las 3 tablas de implante:
UPDATE marcas 
SET estatus = 0
WHERE id NOT IN (
    SELECT DISTINCT marca_id FROM generador_implantado WHERE marca_id IS NOT NULL
    UNION
    SELECT DISTINCT marca_id FROM electrodo_verticular_implantado WHERE marca_id IS NOT NULL
    UNION
    SELECT DISTINCT marca_id FROM electrodo_auricular_implantado WHERE marca_id IS NOT NULL
);

-- B) Desactivar modelos que no existan en ninguna de las 3 tablas de implante:
UPDATE modelos 
SET estatus = 0
WHERE id NOT IN (
    SELECT DISTINCT modelo_id FROM generador_implantado WHERE modelo_id IS NOT NULL
    UNION
    SELECT DISTINCT modelo_id FROM electrodo_verticular_implantado WHERE modelo_id IS NOT NULL
    UNION
    SELECT DISTINCT modelo_id FROM electrodo_auricular_implantado WHERE modelo_id IS NOT NULL
);

7. QUERY DE VERIFICACIÓN POST-ACTUALIZACIÓN
================================================================================

-- Marcas activas visibles en la interfaz:
SELECT id, marca, tipo_marca_id, estatus 
FROM marcas 
WHERE estatus = 1 
ORDER BY tipo_marca_id, marca ASC;

-- Modelos activos visibles en la interfaz:
SELECT mo.id, mo.modelo, mo.marca_id, ma.marca, mo.estatus 
FROM modelos mo 
JOIN marcas ma ON mo.marca_id = ma.id 
WHERE mo.estatus = 1 
ORDER BY ma.tipo_marca_id, mo.marca_id, mo.modelo ASC;
